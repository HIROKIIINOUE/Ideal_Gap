## デザインシステム指針（Apple HIG に準拠したモダンで高級感のあるUI）

- 目的: アプリ全体で統一された高級感のある体験を提供し、Apple Human Interface Guidelines の思想に沿ったモバイルファーストのデザインを実現する。

### コア原則
- 明確さと階層: 主要アクションを視覚的に強調し、余白とコントラストで情報階層を示す。
- 一貫性: 配色・タイポグラフィ・コンポーネントのスタイルを全画面で統一する。
- 触感と奥行き: 微細な影・ブラー・トランジションを最小限に使い、控えめな立体感で高級感を演出する。
- アクセシビリティ: コントラスト比は最低 4.5:1 を目安に確保し、タップ領域は 44x44pt 以上を維持する。

### カラーパレット（黒×ダークブルー基調）
- **Base Background**: `#0B0D11`（最暗ベース、全面背景）
- **Surface**: `#0F1C2F`（カードやモーダルの面）
- **Overlay**: `rgba(12,18,32,0.7)`（モーダル背景やガラス風オーバーレイ）
- **Accent Primary**: `#1E5EFF`（主要アクション、リンク、強調ラベル）
- **Accent Subtle**: `#6EA8FF`（ホバー/フォーカス/軽い強調）
- **Text Primary**: `#E9EDF7`（主要テキスト）
- **Text Secondary**: `#9FB2D0`（補足テキスト、ラベル）
- **Border/Divider**: `rgba(255,255,255,0.08)`（1px ライン、薄い区切り）
- **Success**: `#38D996` / **Warning**: `#F2C94C` / **Error**: `#F25F5C`
- グラデーション推奨例: `linear-gradient(135deg, #0B0D11 0%, #0F1C2F 45%, #1E5EFF 100%)` をヘッダーやヒーローで使用可。使いすぎず要所のみ。

### タイポグラフィ
- ベース: iOS/Android のシステムフォント（SF Pro / Roboto）を使用し、余計なフォント追加は避ける。
- スケール例: 32/28/24 (大見出し), 20/18 (セクションタイトル), 16 (本文/ボタン), 14 (補足)。行間は文字サイズの 1.3〜1.5 倍を目安にする。
- 文言は簡潔に、タイトルは動詞で始めず名詞形で統一。

### スペーシングとレイアウト
- 4pt グリッド（4/8/12/16/24/32）で揃える。コンポーネント間は 12〜16pt、カード内は 16〜20pt を基準。
- 角丸: カード/モーダル 16〜20pt、入力 12〜16pt、ボタン 12〜16pt。高級感を損なわない範囲で控えめに。
- 影/ブラー: `shadow-opacity 0.12` 前後、`shadow-radius 12–18`（プラットフォーム差を考慮）。ブラーは控えめに。

### コンポーネント運用ガイド
- ボタン: Primary は `Accent Primary` 塗りつぶし＋白文字。Secondary はアウトライン（`Border/Divider`）＋文字 `Text Primary`。ローディング時はスピナーを右側に。
- 入力: 背景 `Surface`、枠線 `Border/Divider`、フォーカス時は `Accent Subtle` のグローか 2px ライン。プレースホルダーは `Text Secondary`。
- カード: 背景 `Surface`、角丸 16〜20pt、1px のボーダーを薄く。内容の区切りに 8px の間隔と薄い仕切りを使う。
- リスト行: 16pt パディング、左右に余白を確保。右側にアイコン/チップを配置する場合も行揃えを維持。
- モーダル/シート: 背景に `Overlay`、内部は `Surface`＋やや大きめの角丸。閉じ動作を明示（閉じるボタン/スワイプ）。
- フィードバック: トースト/スナックは下部固定、色は状態カラー。エラー時は明確な文言と再試行アクションを提供。
- アイコン: Expo Vector Icons または React Native Elements のアイコンを使用可。線幅は中程度、サイズは 20〜28pt を基準に統一。

### モーション
- トランジションは 180–260ms 程度で統一し、イージングは `ease-out` ベース。画面遷移はフェード＋スライドの軽い動きに留める。
- アニメーションは意味を持たせ、常時ループを避ける。アクセシビリティ設定でモーション軽減を尊重する。

### アクセシビリティと状態
- コントラストを保ち、フォーカスリングを明示（2px アウトラインを `Accent Subtle` で表示）。
- 非活性状態は透明度で表現するが 50% 以下に落としすぎない。エラーは文言＋色＋アイコンで多重に示す。

### 実装時のリファレンス
- 新規画面/コンポーネントを作成する際は、このドキュメントの配色・タイポ・スペーシング・モーション基準を順守する。
- 既存と異なるデザイン要素を導入する場合は、目的と理由を記載した上で合意を取る。
