# Androidデザイン修正

iOSとAndroidでデザインの差異が出てしまっているためiOSのデザインには一切影響が出ないように以下の箇所を修正していく。
また以下ほとんど修正箇所はiOSにおいては完璧なのでAndroidのみ修正していきたい。(iOSでも修正が必要な場合は冒頭に記載しています。)

- (Androidのみ)LPのCTAボタンの光沢アニメーションにおいて開始地点と終着点が露出してしまっており、アニメーション後もCTAボタン右側に光沢が残ってしまっている。
- (Androidのみ)LPの日本語の文言のみ少し大きすぎるので全体的に小さくする
- (Androidのみ)ログインページ「ログインボタン」と「無料でサインアップへボタン」とサインアップページの「サインアップを続けるボタン」、メールリセットページの「リセットメール送信」に不要なunder borderが表示されているように見える。サインアップページの「ログインへ」ボタンは正常なのでこれを参考にしてほしい
- (これはiOSも)LPの「６つの柱カード」と「料金プランカード」の両方でリストを使用しているが、リストスタイルが異なっているので揃えて欲しい。
- (Androidのみ)全てのインプット項目においてKeyboardAvoidが効いていない
- ダッシュボードページ上部にある「ダッシュボード」文言のスタイルをもう少しスタイリッシュなフォントにして欲しい。
- (Androidのみ)ダッシュボードページの６つの機能のタイトルが日本語の場合のみ大きすぎるので小さくしてほしい。
- (Androidのみ)各機能ページのタイトルカード内のタイトルが日本語の場合のみ大きすぎるので小さくしてほしい。
- (Androidのみ)休憩通知機能の日付ピッカーで日付しか選べない(時間を選択できない)。また通知ボタンを押すとクラッシュしてしまう。
